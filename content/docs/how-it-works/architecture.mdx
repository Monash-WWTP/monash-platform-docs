## Why these boundaries exist

The API owns authorization and projections; a visible client control cannot grant access. Private photos are objects referenced by database-owned IDs, not public object paths. Laboratory observations retain censoring and provenance. Runs snapshot resolved assumptions so editing a scenario cannot silently change an old result.

The monorepo separates web, Android and API releases. This manual is a separate static repository with a pinned source inventory, rather than another deploy-time dependency of the platform.
