API schema defaults and stored scenarios may resolve values differently from a newly constructed simulation dataclass. The immutable `input_snapshot` is the authority for what an actual run used. Do not copy a default table into a claimed plant measurement.

## Maintenance and comparison provenance

Record event unit, start date, duration and availability percentage; dates are end-exclusive. Compare only compatible model/artifact/date outputs. A changed factor, threshold, capacity or influent assumption is a methodological/input change to disclose, not an experimentally demonstrated process benefit.
