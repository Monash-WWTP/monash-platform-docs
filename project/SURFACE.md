# Documentation surface direction
Mode: Read. User pinned official Fumadocs components and landing layout, so no alternative visual world is introduced.
Thesis: a role/task manual with visible source boundaries, rather than chronological progress notes.
Own world: native Fumadocs HomeLayout/DocsLayout; Manrope; platform green, charcoal and white with a readable dark variant.
Story: identify actual version/role, complete a workflow, inspect methods and evidence.
First viewport: direct product-documentation title, concise purpose, manual entry, visible availability callout and role cards. Standard docs navigation/TOC on reading pages.
Form: official static Next/MDX template; no custom replacement widget framework, generated illustrations or marketing metrics.
Finish: built desktop/mobile/browser checks, independent review and verification record; shipped raster provenance is not applicable because no raster imagery is introduced.
